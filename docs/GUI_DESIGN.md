# V2.0 图形界面设计草案

## 目标

`V2.0 Graphical Version` 的目标是把已经稳定的终端版游戏内核展示成一个可视化窗口，而不是重写规则。

图形版第一阶段只解决：

- 看得到棋盘；
- 看得到单位；
- 看得到商店、备战席和玩家状态；
- 能用鼠标完成基础准备阶段操作；
- 能观看自动战斗结果。

## 技术选择

建议使用 raylib。

原因：

- C 语言友好；
- API 简单；
- 足够绘制棋盘、卡牌、按钮和文本；
- 适合作为学习图形界面的第一步。

图形版应作为独立入口存在：

```text
autochess.exe      终端版
autochess_gui.exe  图形版
```

终端版必须继续保留并保持测试全绿。

## 窗口布局

建议窗口尺寸：

```text
1280 x 720
```

基础布局：

```text
┌────────────────────────────────────────────────────────────┐
│ 顶部状态栏：回合、生命、金币、等级、经验、锁店状态          │
├───────────────┬──────────────────────────┬────────────────┤
│ 左侧信息面板   │ 中央棋盘 8 x 7            │ 右侧详情面板    │
│ 羁绊/装备/日志 │ 敌方半场 + 玩家半场        │ 选中单位详情    │
├───────────────┴──────────────────────────┴────────────────┤
│ 底部：商店 5 格 + 备战席 9 格 + 操作按钮                    │
└────────────────────────────────────────────────────────────┘
```

## 视觉元素

### 棋盘

- 8 行 x 7 列；
- 敌方半场和玩家半场使用不同底色；
- 格子中显示单位名称缩写、星级、血条和法力条；
- 选中单位时高亮所在格。

### 单位卡牌

商店和备战席中的单位以卡牌显示：

- 英雄名；
- 费用；
- 星级；
- 职业/阵营；
- 简短属性，例如生命、攻击、技能名。

### 状态栏

顶部状态栏显示：

- 当前回合；
- 玩家生命；
- 敌方生命；
- 金币；
- 等级；
- 经验；
- 当前上场人数；
- 商店是否锁定。

### 右侧详情

选中单位后显示：

- 英雄名；
- 星级；
- 生命、攻击、护甲、魔抗；
- 暴击率、暴击伤害；
- 法力值；
- 技能；
- 羁绊；
- 当前装备。

### 左侧信息

左侧用于显示：

- 当前羁绊；
- 装备库存；
- 最近战斗日志摘要；
- 推荐操作提示。

## 鼠标交互

第一阶段建议只做点击式交互，不急着做拖拽。

准备阶段：

- 点击商店卡牌：购买英雄；
- 点击备战席单位：选中单位；
- 点击己方棋盘格：部署或移动选中单位；
- 点击已上场单位：选中单位；
- 点击备战席空位：撤回选中上场单位；
- 点击装备：给选中单位装备；
- 点击锁店按钮：切换锁店；
- 点击刷新按钮：刷新商店；
- 点击自动按钮：自动部署和自动装备；
- 点击开始战斗按钮：进入战斗。

战斗阶段：

- 第一版可以快速播放，不需要实时动画；
- 后续再加入逐步播放、暂停和回放。

## 阶段路线

### V2.1 GUI Skeleton

- 新增 `autochess_gui` 可执行文件；
- 打开 raylib 窗口；
- 绘制空棋盘；
- 绘制基础状态栏；
- 能关闭窗口；
- 不影响终端版构建。

当前实现状态：

- 已新增 `AUTOCHESS_BUILD_GUI` CMake 开关；
- 已新增 `src/gui_main.c`；
- 默认构建不启用 GUI；
- 开启 GUI 时会绘制窗口、状态栏、空棋盘、左右面板和商店预览。

### V2.2 Board View

- 根据当前 `GameContext` 绘制棋盘单位；
- 绘制备战席；
- 绘制商店；
- 显示玩家状态。

当前实现状态：

- 已绘制玩家和敌方已部署单位；
- 已绘制备战席前三格预览；
- 已绘制商店预览；
- 已绘制一个单位详情面板；
- 暂时使用 `H#` 显示英雄模板编号，中文字体加载留到后续 UI polish。

### V2.3 Preparation Interaction

- 点击购买；
- 点击部署；
- 点击移动；
- 点击撤回；
- 点击自动；
- 点击开始战斗。

当前实现状态：

- 已新增 GUI 选中状态和底部消息栏；
- 点击商店卡牌会调用 `shop_buy_slot` 购买英雄；
- 点击备战席单位会选中该单位；
- 选中备战席单位后，点击己方棋盘空格会调用 `player_deploy_from_bench` 部署；
- 选中己方已上场单位后，点击己方棋盘空格会调用 `player_move_deployed_unit` 移动；
- 选中己方已上场单位后，点击空备战席会调用 `player_return_unit_to_bench` 撤回；
- 右侧按钮支持刷新商店、锁店/解锁、自动部署/装备和执行一场战斗；
- 这一版暂不做拖拽、中文字体加载和战斗动画。

### V2.4 Battle Visualization

- 显示战斗阶段；
- 显示单位血条变化；
- 显示攻击和技能日志；
- 第一版可以按回合刷新，不强求动画。

当前实现状态：

- 点击 Battle 后会记录最近一场战斗摘要；
- 右侧面板显示战斗回合、胜负结果、双方生命变化和双方上场人数；
- 胜负产生装备奖励时，会显示奖励归属和奖励装备；
- 战斗结束后如果游戏仍在进行，会自动进入下一轮准备状态；
- 这一版暂不做逐帧动画、完整攻击日志和中文字体加载。

### V2.5 UI Polish

- 改善卡牌样式；
- 增加颜色编码；
- 增加悬停提示；

当前实现状态：

- 已新增统一文本绘制助手；

### V2.6 Equipment Interaction

- 显示装备库存；
- 点击装备给选中单位穿戴；
- 支持替换已穿戴装备；
- 显示库存不足或未选择单位等错误提示。

当前实现状态：

- 左侧信息面板已显示基础装备库存；
- 点击装备库存会调用 `player_equip_unit`；
- 选中备战席或己方棋盘单位后，可以点击装备穿戴或替换；

- 这一版暂不做拖拽、装备合成和装备详情弹窗。

### V2.7 Equipment Insight

- 选中单位后显示装备适配分；
- 高亮当前库存中最推荐的装备；
- 标记当前已穿戴装备；
- 复用 AI 装备评分逻辑。

当前实现状态：

- 当前库存中评分最高的可用装备会以绿色高亮；

- 这一版暂不做详细评分公式拆解和装备详情弹窗。

### V2.8 Equipment Detail

当前实现状态：

## 不做事项

图形版第一阶段暂不做：

- 联网；
- 八人对局；
- 复杂动画；
- 音效；
- 皮肤；
- 存档；
- 外部资源包；
- 商业级 UI。

## 关键原则

1. 复用现有规则接口  
   图形界面不直接改写游戏数据，应调用 `player`、`shop`、`ai`、`game` 等已有接口。

2. 终端版继续可用  
   图形版是新增入口，不替代终端版。

3. 先可用，再好看  
   第一阶段优先完成信息展示和鼠标操作，视觉美化放后。

4. 每一步都能测试  
   规则逻辑继续由现有测试保护，图形层只做展示和输入转发。
