# 核心规则草案

本文记录终端版 `V1.0` 预期包含的主要游戏规则。早期版本只实现其中一部分。

## 1. 游戏模式

第一版只做：

```text
单人玩家 VS 电脑 AI
```

暂不做八人对局和联网。

## 2. 回合流程

完整回合大致为：

```text
回合开始
  -> 结算收入
  -> 刷新商店
  -> 玩家购买、出售、调整阵容
  -> 计算羁绊
  -> 玩家确认准备
  -> AI 购买和布阵
  -> 战斗初始化
  -> 自动战斗
  -> 结算胜负和扣血
  -> 进入下一回合
```

## 3. 玩家属性

初始建议：

| 属性 | 初始值 |
|---|---:|
| 生命值 | 100 |
| 金币 | 10 |
| 等级 | 3 |
| 经验值 | 0 |
| 商店位置 | 5 |
| 备战席位置 | 9 |

等级决定最大上场人数。

`V0.3` 中，玩家结构已经包含生命值、金币、等级、备战席和拥有单位。经济消费暂未启用。

## 4. 经济系统

基础规则：

- 每回合基础收入：5 金币；
- 利息：每 10 金币增加 1 金币，最多 5 金币；
- 刷新商店：2 金币；
- 购买 4 经验：4 金币；
- 购买英雄：消耗对应费用。

连胜和连败奖励放到后续版本。

`V0.4` 已实现基础收入、利息、刷新消耗、购买经验和升级。当前升级规则简化为每 4 经验升 1 级，后续可以替换为更接近正式自走棋的等级经验表。

## 5. 棋盘

棋盘采用方格：

```text
8 行 x 7 列
```

建议划分：

- 敌方区域：第 0 到 3 行；
- 玩家区域：第 4 到 7 行；
- 每个格子最多一个单位；
- 玩家只能在自己的半场部署。

`V0.2` 中，棋盘先用于战斗模拟。玩家手动部署命令会在后续版本加入。

`V0.3` 中，玩家可以把备战席单位部署到自己半场，并受到等级上场人数限制。

## 5.1 备战席和部署

基础规则：

- 备战席有 9 个位置；
- 新获得的单位先进入备战席；
- 玩家只能把单位部署到自己的半场；
- 敌方只能部署到敌方半场；
- 目标格已被占用时不能部署；
- 上场人数不能超过玩家等级；
- 已部署单位可以移动到己方半场其他空格；
- 已部署单位可以撤回备战席。

## 6. 商店

商店一次出现 5 名英雄。英雄费用分为：

```text
1费、2费、3费、4费
```

早期不做共享卡池，只按等级概率随机生成。

`V0.4` 已实现商店刷新和购买。当前英雄池只有 1 费和 2 费英雄，因此等级概率会先映射到已有费用。后续加入 3 费和 4 费英雄后，再补全完整概率表。

## 7. 升星

规则：

```text
3 个相同一星英雄 -> 1 个二星英雄
3 个相同二星英雄 -> 1 个三星英雄
```

建议属性倍率：

| 星级 | 生命值倍率 | 攻击力倍率 |
|---:|---:|---:|
| 1星 | 1.0 | 1.0 |
| 2星 | 1.8 | 1.7 |
| 3星 | 3.2 | 3.0 |

`V0.5` 已实现自动升星。购买或加入备战席后，如果满足三合一条件，会自动合成。合成会保留一个单位，消耗另外两个单位。被消耗单位不会进入战斗，也不会继续占用备战席。

## 8. 战斗规则

完整版本的战斗采用离散 Tick 模拟。

每个 Tick 中，单位大致执行：

1. 判断是否存活；
2. 判断当前目标是否有效；
3. 没有目标则重新选择目标；
4. 目标在攻击范围内则攻击；
5. 目标不在范围内则移动；
6. 法力值满则释放技能；
7. 检查死亡；
8. 检查战斗是否结束。

早期版本不需要真实等待时间，可以快速模拟并输出关键日志。

## 8.1 羁绊

`V0.6` 已加入职业和阵营字段。

当前已生效羁绊：

```text
2 守卫：守卫单位增加 25 最大生命值
4 守卫：守卫单位增加 60 最大生命值
2 剑士：剑士单位攻击力增加 15%
4 剑士：剑士单位攻击力增加 35%
```

游侠、法师和阵营羁绊目前只建模，具体效果后续加入。

## 9. 目标选择

`V0.1` 临时策略：

1. 选择当前生命值最低的敌人；
2. 生命值相同时，选择实例编号较小者。

后续加入棋盘坐标后，基础优先级升级为：

1. 选择曼哈顿距离最近的敌人；
2. 距离相同时，选择剩余生命值较低者；
3. 仍然相同时，选择实例编号较小者。

这样可以让测试结果稳定。

## 10. 移动规则

`V0.2` 使用简单贪心移动：

1. 如果目标在攻击范围内，单位直接攻击；
2. 如果目标不在攻击范围内，单位尝试向目标移动一步；
3. 优先尝试横向缩短距离；
4. 横向被阻挡时，尝试纵向缩短距离；
5. 如果目标格越界或被占用，单位原地等待。

## 11. 战斗属性规划

最终战斗单位会逐步拥有：

- 生命值；
- 攻击力；
- 护甲；
- 魔抗；
- 攻击速度；
- 攻击距离；
- 当前法力值；
- 最大法力值；
- 暴击率；
- 暴击伤害；
- 技能编号；
- 位置；
- 存活状态；
- 当前目标。

`V0.1` 只保留生命值、攻击力和存活状态，其他词条后续版本逐步加入。

## 12. 后期扩展

后期可以加入：

- 装备；
- 更复杂技能；
- 更强 AI；
- 数据文件驱动英雄；
- 图形界面；
- 音效和动画。

这些不进入终端版早期主线。
