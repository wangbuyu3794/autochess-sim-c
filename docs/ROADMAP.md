# 版本路线

本路线用于框定项目范围，防止开发无限扩张。实际开发过程中可以根据学习效果和实现难度调整。

## V0.1 Battle Simulator

目标：完成最小战斗模拟。

包含：

- 基础 CMake 工程；
- 英雄和战斗单位结构；
- 双方固定 3 个单位；
- 普通攻击；
- 最近目标选择；
- 生命值和死亡；
- 胜负判断；
- 中文战斗日志；
- 基础测试。

不包含：

- 商店；
- 经济；
- 棋盘部署；
- 备战席；
- 羁绊；
- 技能；
- AI 运营；
- 存档；
- 图形界面。

学习重点：结构体、数组、函数拆分、基础测试。

## V0.2 Board And Movement

目标：加入棋盘和简单移动。

包含：

- 8x7 方格棋盘；
- 双方半场；
- 单位部署；
- 攻击距离；
- 简单贪心移动；
- 越界和占位检查。

学习重点：二维数组、坐标、边界检查。

## V0.3 Player And Bench

目标：加入玩家和备战席。

包含：

- 玩家结构；
- 备战席；
- 单位部署、撤下和移动；
- 上场人数限制；
- 基础终端命令。

学习重点：模块接口、状态管理。

## V0.4 Shop And Economy

目标：加入商店和经济系统。

包含：

- 金币；
- 回合收入；
- 利息；
- 商店刷新；
- 购买英雄；
- 等级抽卡概率。

学习重点：随机数、概率、资源系统。

## V0.5 Merge System

目标：加入升星。

包含：

- 三个相同一星合成二星；
- 三个相同二星合成三星；
- 属性倍率；
- 自动合成测试。

学习重点：数组查找、删除、合并、边界测试。

## V0.6 Trait System

目标：加入羁绊。

包含：

- 职业和阵营；
- 羁绊统计；
- 阈值判断；
- 属性加成。

学习重点：枚举、计数表、数据驱动设计。

## V0.7 Skills And Mana

目标：加入法力和技能。

包含：

- 攻击回蓝；
- 技能释放；
- 单体伤害；
- 群体伤害；
- 护盾；
- 治疗或控制的基础版本。

学习重点：技能分发、函数指针或策略表。

## V0.8 Operation AI

目标：加入电脑运营 AI。

包含：

- AI 购买；
- AI 刷新；
- AI 升星；
- AI 自动布阵；
- 阵容评分。

学习重点：评分函数、简单决策系统。

## V0.9 Full Match Loop

目标：完成多回合对局。

包含：

- 主状态机；
- 多回合流程；
- 玩家生命值；
- 胜负扣血；
- 游戏结束。

学习重点：状态机、主循环、流程控制。

## V1.0 Terminal Release

目标：形成可发布的终端正式版。

包含：

- 保存和读取；
- 数据文件；
- 完整帮助命令；
- README 和文档补齐；
- 测试补齐；
- 平衡性调整。

学习重点：文件 IO、工程整理、发布准备。

## V2.0 Graphical Version

目标：使用 raylib 制作图形版。

包含：

- 窗口；
- 棋盘绘制；
- 鼠标操作；
- 英雄卡牌；
- 血条和法力条；
- 简单动画。

该阶段等待终端版稳定后再启动。
