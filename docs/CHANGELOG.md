# Changelog

## Unreleased

- 进入 `V2.9 Battle Log View`。
- GUI 点击战斗时会捕获核心战斗日志，并在右侧显示最近几条过程记录。
- 战斗日志复用现有 `FILE *log_stream` 输出路径，不新增独立战斗规则。
- 战斗后会清空单位选择，让右侧面板优先展示摘要和日志。
- 进入 `V2.8 Equipment Detail`。
- GUI 会在点击装备后显示右侧装备详情。
- 装备详情包含库存、属性加成、当前单位适配分和适用定位提示。
- 装备详情复用现有装备数据和 AI 评分，不新增独立规则。
- 进入 `V2.7 Equipment Insight`。
- GUI 装备库存会在选中单位后显示每件装备的适配分。
- GUI 会高亮当前库存中对选中单位评分最高的装备。
- 装备适配分复用 `ai_score_equipment_for_unit`，不新增独立 GUI 评分规则。
- 当前已穿戴装备会在库存列表中标记为已穿。
- 进入 `V2.6 Equipment Interaction`。
- GUI 左侧信息面板新增装备库存列表。
- 图形版支持点击装备库存，为当前选中的玩家单位穿戴或替换装备。
- 装备点击会复用 `player_equip_unit`，遵守库存不足、单位未选择和装备无效等规则错误。
- 底部操作反馈会显示装备穿戴成功或失败原因。

- 底部操作反馈改为中文提示，并保留规则错误原因。
